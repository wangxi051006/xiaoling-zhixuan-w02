# 02 配送端（骑手端）

面向骑手：员工登录、接单、取货、送达和收入记录。入口为 [`entry.ts`](entry.ts)，样式在 [`app.css`](app.css)，对应页面是 [`web/rider.html`](../../rider.html)。

移动端布局分三段：底部「订单 / 消息 / 我的」。订单页用「任务大厅 / 待取货 / 配送中」三个分段管理任务，支持批量抢单、批量取货和批量送达；我的页汇总今日单量、今日收入、工作状态、钱包、订单历史和骑手单量排行榜。改版范围与截图见 [`apps/rider-app/evidence/ui-redesign`](../../../apps/rider-app/evidence/ui-redesign/README.md)。

在 `web/` 目录统一开发、测试和构建；共用接口与入口逻辑在 [`src/shared/`](../shared/) 下。
