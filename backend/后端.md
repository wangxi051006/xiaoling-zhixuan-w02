# 04 后端

Go API 及后台业务任务，为用户、配送和管理三端提供服务。

| 路径 | 内容 |
| --- | --- |
| [`cmd/api/`](cmd/api/) | API 服务启动入口 |
| [`internal/`](internal/) | 身份、商品、履约、预约、结算等业务模块 |
| [`migrations/`](migrations/) | PostgreSQL 迁移，保留完整 `000–060` 链 |
| [`test/integration/`](test/integration/) | 隔离数据库集成测试 |

在本目录执行 `go test -mod=readonly ./...`。本地服务配置与数据库初始化参照[部署说明](../deploy/README.md)及[配置模板](../deploy/env.example)，不要直接使用生产配置。
