# P06 · 三端前端迁移与实联调实施

> G0 后用契约 mock 开工、G2 后实联调。写域 `web/src/{user,rider,admin}/` 与 `web/tests/`；共享依赖、生成 API 与 Vite 接线由总控处理。保留 `demo/` 和根 `index.html` 原样。

[总计划](./00-master.md) · [契约](./10-contracts.md) · [验收](./08-acceptance.md)

## 执行步骤

- [ ] 对照 `demo/ui-user.js`、`ui-delivery.js`、`ui-admin.js` 和 `app.css` 为三端列出保留组件、骨架/空态/错误态和替换数据；记录原型在 390px 的对比基线。移植自绘样式、表单和交互，不显示原型切端、重置和种子数据；使用默认转义，键盘可操作，表单报错和状态提示可读。
- [ ] `web/src/user/`：搜索/详情、规格、非敏感本地购物袋、楼栋地址、即时/预约选择、动态窗口、服务器报价、去结算、订单时间轴、取消和再买。先写 E2E 验证时段满/变价必须重确认、同一操作重试复用幂等键、余额不足不切 COD、微信「待接入」禁用。成功页分别显示“送达后付款”或“余额已扣”，不能仅因提交请求发出便显示成功。
- [ ] `web/src/rider/`：上线、本地时间窗口、站点大厅、取送、拒付/退回、站内消息、本人历史/收入。测试大厅无精确地址、抢单冲突刷新、同一时刻只发一组轮询，隐藏标签页暂停、退避和旧响应不覆盖新数据；COD 送达时确认实际全额收款，拒付按钮不算送达。移除假提现、定位、优惠/抢单造假和假 ETA。
- [ ] `web/src/admin/`：商品/库存/促销、窗口和容量、预约待备货/逾期、订单/取消/分拣归架、骑手管理、COD 上缴复点、退款审批和对账。仅按 `/me` 和 API 权限显隐；服务端拒绝仍要能正确展示。指标来自后台，没有数据就显示无记录，操作者/审批人在独立会话完成操作。
- [ ] 在 `web/tests/` 建 3 个浏览器上下文的端到端脚本；W1 mock 仅限测试构建。G2 后改接真实预发接口，运行即时 COD、预约 COD、预约到时唤醒、预约余额取消、余额不足、微信拒绝、骑手拒付退回和运营对账。桌面和 390px 移动视口记录截图，验证无溢出、遮挡或控制台错误。
- [ ] G3 提交三个静态入口构建与真实 API 证据；证据不含敏感地址。未接短信的测试环境允许合成测试登录，但与生产构建/环境明确隔离。

**命令：** 在 `web/` 执行 `npm ci`、`npm run typecheck`、`npm test`、`npm run build`、`npm run test:e2e`；G3 另用预发环境变量配置真实站点 API，运行同一测试脚本。**证据：** `UI-01/02` 及关联分支；mock 报告必须标注模拟。
